# Telegram Business assistant

Личный Telegram Business-бот для просмотра доступных личных сообщений и подготовки ответов. Бот показывает входящее сообщение владельцу, принимает ответ текстом или голосовым, показывает черновик и отправляет его контакту **только после нажатия «Отправить»**. Фото, видео и стикеры проходят через такое же подтверждение. Стиль можно применить кнопкой под черновиком; исходный текст всегда доступен без переформулирования.

## Функции

- `/chats` — известные чаты; `/alias ID Имя` — удобное имя контакта.
- Ответ на копию входящего сообщения или `/send Имя текст` — черновик для отправки.
- `/remember Имя | факт`, `/memory Имя`, `/forget ID` — заметки о контактах и договорённостях.
- `/mission Имя | цель | ограничения`, `/stopmission Имя` — локальная модель предлагает следующий ответ после нового сообщения. Каждый ответ требует подтверждения.
- `/find слова` — поиск по новым сообщениям, включая распознанные голосовые и текст на фото. Архив сообщений очищается через 90 дней; заметки удаляются отдельно.
- Длинные сообщения, голосовые, видео и фото разбираются в фоне, чтобы бот продолжал отвечать на команды.
- `/help` — полный список команд в Telegram.

Бот использует локальные Qwen через llama.cpp, faster-whisper для речи и RapidOCR для текста на фото. Языковой API-ключ не нужен. Для получения и отправки сообщений нужен доступ к Telegram Bot API. Telegram Business даёт боту только те личные чаты, которые открыты ему в настройках, и ограничивает отправку первым сообщением контакту.

## Обновление существующего Windows Server

Файл [deploy/four_features.ps1](deploy/four_features.ps1) — автономное обновление существующей установки в `C:\TelegramAssistant`. Оно загружает OCR-зависимости через локальный Happ HTTP-прокси `127.0.0.1:10809`, проверяет их, создаёт резервную копию исходников и перезапускает задачу `TelegramPersonalAssistant`. Для обновления скопируйте файл на сервер в `C:\PriceBot\four_features.ps1` и выполните в PowerShell администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\PriceBot\four_features.ps1"
```

Токен бот читает из уже настроенного защищённого хранилища сервера. Установщик переносит ID владельца из существующего `bot.py` в новую копию на сервере; в исходниках ID не хранится. Данные чатов находятся только на сервере в `data/bot.sqlite3` и не входят в репозиторий. Крупные модели, Python runtime и личная база также не публикуются.

## Разработка и проверка

Python 3.12, зависимости из `requirements.txt`. Тесты:

```powershell
python -m unittest discover -s tests -v
```

Для запуска бота требуются переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_OWNER_ID`. В Windows Server их передаёт установленный скрипт запуска. Для иных окружений настройте эти переменные самостоятельно и запустите `python bot.py`. Локальная Qwen должна слушать `127.0.0.1:18765`; без неё работают приём сообщений и исходные черновики, а стилизация и предложения миссии будут недоступны.
